# Как добавить скин фишек

Скины регистрируются сами, ничего «зашитого» в игре нет: ни список скинов,
ни карточки в настройках, ни названия. Нужно **один файл + две строки**.

## 1. Файл `js/skins/<id>.js`

Скопируйте `_template.js` (файлы с `_` игнорируются) и поправьте:

```js
Tileset.register({
  id: 'neon',                    // a-z, 0-9, дефис; совпадает с именем файла
  name: 'Неон',                  // название на карточке
  desc: 'Светящиеся линии',      // подпись на карточке
  order: 50,                     // порядок в списке (меньше — выше)
  face: (suit, rank) => TilesetCore.svg('…внутренности <svg>…'),
  // names: { … }                // необязательно: свои названия фишек
});
```

`face(suit, rank)` вызывается один раз на **вид** фишки (34 + бонусные),
состав 144 фишек и правила совпадения собирает `TilesetCore`. Нужен полный
контроль — вместо `face` дайте `create()`, возвращающий `{ tiles, isMatch, groups }`
(примеры: `classic.js`, `ornate.js`).

Набор строится лениво, при первом выборе скина, — лишние скины не тормозят старт.

## 2. Две строки подключения

- `index.html` — тег `<script src="js/skins/neon.js"></script>` **после** `js/tileset.js`
  (в блоке со скинами);
- `sw.js` — `'./js/skins/neon.js',` в блоке со скинами (иначе скин не попадёт в офлайн-кэш).
  При выпуске поднимите версию кэша `CACHE_NAME`.

## 3. Проверка

- Консоль браузера: `Tileset.validate('neon')` → `[]`, если набор годен
  (144 фишки, уникальные id, 34 вида, у каждой `face` — `<svg>`, без скриптов).
- `node tests/run.js` — тест `skins-registry` сам проверяет, что каждый файл
  из `js/skins/` подключён в `index.html` и `sw.js` (в правильном порядке) и
  что скин проходит `validate`. Забыть строку не получится.

## Что делает за вас реестр

Карточка с образцами в «Настройки → Скин фишек», название в тосте и в превью,
проверка сохранённого скина (удалили файл — игра вернётся к `classic`),
защита от ошибок: скин, который не построился, пропадает из списка, а игра
продолжает работать на скине по умолчанию.
